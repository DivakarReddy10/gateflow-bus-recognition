# GateFlow – Bus Gate Monitoring System

GateFlow is a web-based bus gate monitoring application built with React, TypeScript, and Vite. It uses OCR-based number plate recognition to identify buses and record their entry (IN) and exit (OUT) movements.

## Features

- Automatic camera-based number plate scanning
- OCR-based bus registration number recognition
- Entry and exit event tracking
- Manual image upload and scanning
- Gate activity dashboard
- Searchable event history and filtering
- CSV export
- Browser-based local storage

## Technologies Used

- React
- TypeScript
- Vite
- Tesseract.js
- Lucide React
- HTML and CSS

## Purpose

To simplify bus gate monitoring and improve the recording of vehicle movements through a browser-based application.

## Running Locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build the application:

```bash
npm run build
```
